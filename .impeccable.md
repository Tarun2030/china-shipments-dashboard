## Design Context

### Users
Primarily Tarun, checked frequently (desktop and mobile) as a live operational brief. Also shared with colleagues/buyers/partners occasionally, so it needs to read as credible and trustworthy to outside eyes, not just a personal scratchpad.

### Brand Personality
Terminal / trading-desk brief. Dense, factual, no-nonsense. Data speaks for itself — the UI gets out of the way. Three words: precise, restrained, operational.

### Aesthetic Direction
Established brutalist/utilitarian data terminal look — do not deviate:
- Typography: IBM Plex Sans (body/UI) + IBM Plex Mono (labels, monospace data, timestamps).
- Palette: near-black on white, grey borders/dividers, color used ONLY as status signal (green = good/paid, amber = partial/pending, red = attention/awaiting payment, blue = in progress). No decorative color.
- Sharp corners throughout, no drop shadows, no glassmorphism, no gradients.
- Dense tabular layout: metric strip, analytics panels, expandable contract/commission tables (desktop) collapsing to card lists (mobile).
- No default theme toggle currently — light only.

### Design Principles
1. Every animation must earn its place by conveying state or giving feedback — never decorative.
2. Keep motion restrained and fast/functional (matches "Restrained & functional" direction) — this is a trading-desk brief, not a consumer app; motion should feel precise, not delightful-for-its-own-sake.
3. Respect `prefers-reduced-motion` always.
4. Since it's occasionally shown to outside colleagues/buyers, motion should read as polished and intentional, not janky or absent — but still restrained, never flashy.
5. No particular performance constraint assumed (modern devices/connections) — standard 60fps CSS/JS animation budget is fine.

### Scoped exception: the "Brief" warm zone (2026-07-16)
Tarun asked for an Ali-Abdaal-style warm/colorful pass on two specific views: the Overview tab's
metrics strip + analytics panels (Business Snapshot / Execution Rate / Buyer Concentration), and the
Commission tab's stats + "Payment Initiated" panel — explicitly **not** the rest of the app (main
Contract/Commission tables, tab bar, header, mobile card lists all stay brutalist).

Implementation: a `.brief` wrapper class applied only around those two regions. It locally
re-defines the existing color tokens (`--black`, `--grey-*`, `--red/--amber/--green/--blue`) to a
warm terracotta-on-cream palette (OKLCH), so every element underneath that already channels color
through those tokens re-tints automatically — no need to touch individual component rules. Adds
rounded corners (18px), a cream card background, and 'Bricolage Grotesque' as a display font for
headline numbers only (body/labels stay IBM Plex Sans/Mono for cohesion with the rest of the page).

If asked to extend the warm treatment further, or to redesign remaining brutalist areas, ask first —
this was scoped narrowly on purpose. If asked to touch `.brief` again, watch for CSS comments
containing a literal `*/` substring (e.g. `--grey-*/--red`-style shorthand) — that silently
truncates the comment early and can make an entire subsequent rule vanish from the parsed
stylesheet without any console error.
